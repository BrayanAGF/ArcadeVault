## Next.js 16 specifics

- Next.js 16.4.6 / React 19.3. Before using any Next.js API, read the matching guide in `node_modules/next/dist/docs/` (01-app/…) — do not rely on memory.
- `next.config.ts` enables `cacheComponents` and `partialPrefetching`. Follow the Cache Components model (`"use cache"`, `<Suspense>` boundaries for dynamic data); see `02-guides/migrating-to-cache-components.md` and `adopting-partial-prefetching.md`.
- Tailwind v4 is loaded via the `@tailwindcss/turbopack` loader rule in `next.config.ts` — there is no PostCSS config; don't add one.
- `AGENTS.md` is regenerated by `next dev` (`experimental.agentFeedback`); commit it as-is, don't strip its block.
- Import alias: `@/*` → repo root.

## Workflow: Spec Driven Design (obligatorio)

- Always write a spec with `/spec` and get it approved before implementing; then implement with `/spec-impl`. No feature code without an approved spec.
- These skills come from Klerith/fernando-skills: `npx skills@latest add Klerith/fernando-skills`. If they're not installed, stop and tell the user.
- Verify with `/verify` (tsc + lint + build) before declaring work done. There is no test framework yet.
